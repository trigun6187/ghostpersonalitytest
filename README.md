# 👻 Ghost Personality Test

An interactive **IPIP Big Five 50-Item Personality Test** based on Goldberg's (1992) International Personality Item Pool.

Built with vanilla HTML, CSS, and JavaScript. Zero dependencies.

## Features

- 🎯 50 scientifically validated IPIP items
- 🎨 Fun, modern glassmorphism UI with animated transitions
- 📊 Interactive radar chart visualization
- ⚡ One-click Likert scale with auto-advance
- ⌨️ Full keyboard support (1-5 for answers, arrow keys for navigation)
- 📱 Mobile-first responsive design
- 🔄 Retake the test anytime — no data stored

👉 https://trigun6187.github.io/ghostpersonalitytest

## Scoring

The test measures the **Big Five** personality traits:
- **Extraversion** — Sociability, energy, assertiveness
- **Agreeableness** — Compassion, cooperation, trust
- **Conscientiousness** — Organization, discipline, reliability
- **Neuroticism** — Emotional sensitivity, reactivity
- **Openness** — Curiosity, creativity, imagination

Each trait is scored from **1.0 (low)** to **5.0 (high)** based on 10 items per trait.
